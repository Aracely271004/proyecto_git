# Proyecto Git - Control de Versiones

## Descripción

Este proyecto fue desarrollado como práctica inicial del uso de Git y GitHub para el control de versiones de proyectos de software.

El objetivo es aprender a:

* Crear repositorios locales con Git.
* Realizar commits.
* Gestionar versiones del proyecto.
* Conectar un repositorio local con GitHub.
* Subir cambios a un repositorio remoto.

## Comandos utilizados

### Inicialización del repositorio

```bash
git init
```

### Agregar archivos al área de preparación

```bash
git add .
```

### Crear un commit

```bash
git commit -m "Primer commit"
```

### Conectar con GitHub

```bash
git remote add origin https://github.com/Aracely271004/proyecto_git.git
```

### Subir archivos al repositorio remoto

```bash
git push -u origin master
```

## Reflexión

### ¿Por qué Git es crítico en proyectos colaborativos?

Git permite que múltiples desarrolladores trabajen simultáneamente en un mismo proyecto sin sobrescribir el trabajo de otros. Además, facilita el seguimiento de cambios, la recuperación de versiones anteriores y la organización del desarrollo mediante ramas.

### ¿Qué problemas evita?

Git evita:

* Pérdida de código.
* Sobrescritura accidental de archivos.
* Conflictos entre versiones.
* Dificultad para rastrear cambios.
* Problemas de coordinación entre desarrolladores.
